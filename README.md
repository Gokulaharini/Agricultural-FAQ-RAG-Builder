## 🚀 Live Demo

Try the **Agricultural FAQ RAG Builder** here:

👉 **[Launch Live Demo](https://agricultural-faq.vercel.app/)**

The live demo allows you to:

- 📄 Upload agricultural PDFs, manuals, FAQs, and extension notes
- 🔍 Build a searchable knowledge base using embeddings and FAISS
- 💬 Ask questions about the uploaded documents
- 🤖 Get answers grounded only in the retrieved document content
- 📚 View source document, page number, and relevant text snippets
- 🖨️ Process scanned PDFs using OCR when required

> **Note:** The quality and scope of answers depend on the agricultural documents uploaded to the knowledge base.
